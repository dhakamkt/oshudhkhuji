# ওষুধখুঁজি · OshudhKhuji

Bangladesh medicine directory — search 26,000+ brands, see every alternative brand of the same generic sorted by price, and read short Bangla/English notes on uses, how it works, side effects and precautions.

- `index.html` — the whole site (single page, Bangla / English)
- `meds.json` — brand, generic, company, form, strength and price data
- `ads.txt`, `robots.txt`, `.htaccess` — hosting files

**Before going live:** edit `const SITE` in `index.html` (domain, email, AdSense ID) and the publisher ID in `ads.txt`. See `GUIDE-bn.txt` for step-by-step instructions in Bangla.

> Information is for general knowledge only and is not medical advice.
